# Project Agora V3 — App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and deploy a single Next.js app with a graphical PRD landing page, a Real-time Incident Management demo, and a Case Management demo — deployed to Vercel from github.com/bgeorge-een/project-agora-v3.

**Architecture:** Next.js 15 App Router, three routes (`/`, `/incident-management`, `/case-management`), shared EEN VMS design tokens in Tailwind v4, two Claude API routes (`/api/enrich`, `/api/investigate`). Mock data in `lib/mock-data/scenarios.ts` drives all demos; no database.

**Tech Stack:** Next.js 15, React 19, TypeScript strict, Tailwind CSS v4, @anthropic-ai/sdk 0.52, Vercel deployment.
